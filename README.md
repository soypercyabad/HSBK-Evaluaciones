# HSBK-Evaluaciones

Descripción
----------
Proyecto Java Maven para la gestión de evaluaciones académicas. Implementa la lógica de negocio para crear, evaluar y consultar evaluaciones. Ajustar esta sección según los requisitos reales del proyecto.

Tecnologías
-----------
- Java 21\+ (o la versión mínima requerida)
- JavaFX
- Maven
- IntelliJ IDEA (recomendado)

Requisitos
--------
- JDK instalado (Java 21\+)
- Maven instalado
- Variables de entorno configuradas (`JAVA_HOME`, `MAVEN_HOME`) si aplica

Instalación y compilación
------------------------
1. Clonar el repositorio:
   ```bash
   git clone https://github.com/soypercyabad/HSBK-Evaluaciones.git
   cd HSBK-Evaluaciones

2. Compilar y empaquetar con Maven::
   ```bash
   mvn clean package
